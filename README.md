# icfes-results-by-internet-access

This repository aims to establish a relation between ICFES results and internet access by Colombian municipalities, using open data from [datos.gov.co](https://datos.gov.co).

---

## Project structure

```
icfes-results-by-internet-access/
├── data/
│   ├── raw_json/
│   │   ├── icfes/
│   │   ├── internet/
│   │   └── bachillerato/
│   ├── parquet/
│   │   ├── icfes/
│   │   ├── internet/
│   │   └── bachillerato/
│   └── parquet_clean/          # produced by transform_clean.py
│       └── ...
├── data.py
├── transform_clean.py
├── requirements.txt
├── 03_coleccion_descripcion_datos.ipynb   # Spanish filename; see Notebooks below
├── 04_exploracion_de_datos.ipynb
├── 05_limpieza_transformacion.ipynb
└── README.md
```

The `data/` directory is generated by `data.py` (and by `transform_clean.py` for `parquet_clean/`) and is listed in `.gitignore`.

- **`data/raw_json/`** — JSON Lines files from the Socrata API, fetched in paginated batches (default batch size is defined as `LIMIT` in `data.py`, currently 5000 rows per request).
- **`data/parquet/`** — Columnar Parquet tables produced by Spark from the raw JSONL.
- **`data/parquet_clean/`** — Cleaned and lightly transformed tables from the PySpark pipeline in `transform_clean.py`.

## Prerequisites

- Python 3.8 or higher
- Java 17 or 21 (required by PySpark)
- Socrata application token (see configuration section)

---

## Configuration

### Socrata token

Before running the ingestion script, export your application token:

```bash
export SOCRATA_APP_TOKEN='your-token-here'
```

### Optional environment variables (Spark)

| Variable | Description | Default |
|---|---|---|
| `SPARK_MASTER_URL` | Master URL in cluster mode (e.g. `spark://host:7077`). If not set, runs in `local[*]` mode. | — |
| `SPARK_DRIVER_MEMORY` | Driver memory. | `2g` (local) / `4g` (cluster) |
| `SPARK_EXECUTOR_INSTANCES` | Number of executors (cluster only). | `3` |
| `SPARK_EXECUTOR_CORES` | Cores per executor (cluster only). | `4` |
| `SPARK_EXECUTOR_MEMORY` | Memory per executor (cluster only). | `8g` |
| `SPARK_DEFAULT_PARALLELISM` | Default parallelism (cluster only). | `instances * cores` |

## Usage

### Full run (extraction + Spark)

Downloads raw data and writes Parquet in one step:

```bash
python3 data.py
```

Parallel downloads across datasets (pagination per dataset stays sequential):

```bash
python3 data.py --parallel-downloads
```

### Extraction only

Downloads `.jsonl` under `data/raw_json/` without running Spark:

```bash
python3 data.py --extract-only
```

### Sample mode (development)

`--sample N` fetches only the first **N rows per dataset** from the API. By default, `data.py` runs **both** extraction and Parquet conversion unless you pass `--extract-only` or `--spark-only`.

```bash
python3 data.py --sample 5000
```

Download JSONL only (no Spark):

```bash
python3 data.py --extract-only --sample 5000
```

You can add `--parallel-downloads` together with the options above.

### Spark processing only

Convert existing `data/raw_json/` to `data/parquet/` (run after you already have JSONL on disk):

```bash
python3 data.py --spark-only
```

### Cleaning and transformation (PySpark)

Reads `data/parquet/`, writes cleaned tables under `data/parquet_clean/`, and prints schema, row counts, and a sample to the console:

```bash
python3 transform_clean.py
python3 transform_clean.py --limit-rows 5000
python3 transform_clean.py --no-write
```

The notebook **`05_limpieza_transformacion.ipynb`** documents the same pipeline for the written report (Section 7).
