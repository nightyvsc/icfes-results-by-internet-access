# icfes-results-by-internet-access

This repository aims to establish a relation between ICFES results and internet access by Colombian municipalities, using open data from [datos.gov.co](https://datos.gov.co).

---

## Project structure
```
icfes-results-by-internet-access/
├── data/
│   ├── raw_json/
│   │   ├── icfes/
│   │   │   ├── part_0000.jsonl
│   │   │   ├── part_0001.jsonl
│   │   │   └── ...
│   │   └── internet/
│   │       ├── part_0000.jsonl
│   │       ├── part_0001.jsonl
│   │       └── ...
│   └── parquet/
│       ├── icfes/
│       └── internet/
├── data.py
├── requirements.txt
└── README.md
```

The `data/` folder is generated automatically by `data.py` and is excluded from the repository via `.gitignore`.

- `data/raw_json/` — `.jsonl` files downloaded from the Socrata API, paginated in batches of 50,000 records.
- `data/parquet/` — Final version of the data in Parquet format, generated by Spark from the raw files.

## Configuration

### Socrata token

Before running the script, export your application token as an environment variable:
```bash
export SOCRATA_APP_TOKEN='your-token-here'
```

### Optional environment variables (Spark)

| Variable | Description | Default |
|---|---|---|
| `SPARK_MASTER_URL` | Master URL in cluster mode (e.g. `spark://host:7077`). If not set, runs in `local[*]` mode. | — |
| `SPARK_DRIVER_MEMORY` | Driver memory. | `2g` (local) / `4g` (cluster) |
| `SPARK_EXECUTOR_INSTANCES` | Number of executors (cluster only). | `3` |
| `SPARK_EXECUTOR_CORES` | Cores per executor (cluster only). | `4` |
| `SPARK_EXECUTOR_MEMORY` | Memory per executor (cluster only). | `8g` |
| `SPARK_DEFAULT_PARALLELISM` | Default parallelism (cluster only). | `instances * cores` |

## Usage

### Full run (extraction + Spark)

Downloads the raw data and generates the Parquet files in one step:
```bash
python3 data.py
```

With parallel download between datasets:
```bash
python3 data.py --parallel-downloads
```

### Extraction only

Downloads the `.jsonl` files to `data/raw_json/` without running Spark:
```bash
python3 data.py --extract-only
```
### Sample mode (development)

Downloads only the first N records per dataset, without running Spark. Useful for testing the pipeline locally without access to the cluster or the full dataset:
```bash
python3 data.py --sample 5000
```
Can be used together with `--extract-only`:
```bash
python3 data.py --extract-only --sample 5000
```

Can be combined with `--parallel-downloads`:
```bash
python3 data.py --extract-only --sample 5000 --parallel-downloads
```

### Spark processing only

Converts files in `data/raw_json/` to Parquet (requires extraction to have been run first):
```bash
python3 data.py --spark-only
```

## Notebooks

### 03_coleccion_descripcion_datos.ipynb

Covers CRISP-DM phase: data collection and description. Loads the three raw JSONL datasets from `data/raw_json/` into Apache Spark (local mode, 2 GB driver) and describes them in terms of schema, attribute meaning, record counts, and basic descriptive statistics.

Datasets loaded:

| Dataset | Socrata ID | Source | Description |
|---|---|---|---|
| ICFES Saber 11 | `kgxf-xxbe` | ICFES | Individual student results for the Saber 11 exam |
| Internet access by municipality | `n48w-gutb` | MinTIC | Fixed internet connections by municipality |
| Educational coverage | `nudc-7mev` | MEN | Educational indicators by municipality and year |

Key findings documented in the notebook:

- All ICFES columns are ingested as `string`. Score columns (`punt_matematicas`, `punt_ingles`) require numeric casting before analysis.
- The `no_de_accesos` column in the internet dataset is stored as a string and may contain special characters. Speed columns use a comma as the decimal separator, requiring cleanup before numeric operations.
- Column names in the educational coverage dataset contain encoding artifacts from accented characters (e.g. `a_o`, `deserci_n`, `aprobaci_n`). These will be normalized in the transformation phase.
- The three datasets can be joined on municipality code and year to build an integrated territorial analysis of connectivity and educational outcomes.

### 04_exploracion_de_datos.ipynb

Performs exploratory data analysis (EDA) on the three datasets loaded from `data/parquet/` using pandas, matplotlib, and seaborn. Numeric columns are cast at load time. The notebook produces 12 analytical elements:

| # | Element | Dataset |
|---|---|---|
| 1 | General descriptive statistics | All three |
| 2 | Null value summary table | All three |
| 3 | Score distribution histograms (English and Mathematics) | ICFES |
| 4 | Average score by socioeconomic stratum and gender (chart and table) | ICFES |
| 5 | Temporal evolution of net coverage by educational level | Educational coverage |
| 6 | Top 10 departments by total internet connections (chart and table) | Internet |
| 7 | Internet access share by technology type (pie chart) | Internet |
| 8 | Correlation matrix among educational indicators | Educational coverage |
| 9 | Boxplot: English score by school type (public vs. private) | ICFES |
| 10 | Household internet access vs. Mathematics score (boxplot and bar chart) | ICFES |
| 11 | Internet access by user segment, residential vs. corporate (table and bar chart) | Internet |
| 12 | Dropout rate ranking by department (best and worst 15) | Educational coverage |

### 05_limpieza_transformacion.ipynb

Documents the cleaning and transformation pipeline implemented in `transform_clean.py`. The notebook serves as an executable entry point for the pipeline; all transformation logic resides in the script. Requires `data/parquet/` to have been generated first by `data.py`.

The pipeline covers: numeric casting and normalization of DANE municipality codes (`lpad` to 5 digits); filtering of ICFES records to `estu_estadoinvestigacion = PUBLICADO` and global scores within the 0-500 valid range; removal of negative internet access values; IQR-based outlier removal (1.5x IQR) on `punt_global` and `no_de_accesos`; mean imputation for `punt_ingles` and `cobertura_neta`; and aggregation of internet connections by municipality and year joined with educational coverage to produce the derived variable `accesos_por_habitante`.

Clean output is written to `data/parquet_clean/` with four subfolders: `icfes`, `internet`, `bachillerato`, and `municipio_internet_cobertura`.

---

## transform_clean.py

PySpark script that implements the full cleaning, filtering, and initial transformation pipeline described in `05_limpieza_transformacion.ipynb`. Reads from `data/parquet/` and writes clean Parquet files to `data/parquet_clean/`. Uses the same Spark session configuration (local and cluster modes) as `data.py`.

### Usage

```bash
python transform_clean.py
python transform_clean.py --limit-rows 5000
python transform_clean.py --no-write
python transform_clean.py --verbose
python transform_clean.py --no-progress
```

### CLI options

| Option | Description |
|---|---|
| `--parquet-dir` | Source directory with `icfes`, `internet`, and `bachillerato` subfolders. Default: `data/parquet`. |
| `--output-dir` | Destination directory for clean Parquet files. Default: `data/parquet_clean`. |
| `--limit-rows N` | Limit each table to N rows after reading Parquet (fast local development). |
| `--no-write` | Run the pipeline without writing output files (dry run). |
| `--verbose` | Print schema, row counts, and `show(20)` for each table. Disables the progress bar. |
| `--no-progress` | Suppress the stage progress bar. |

### Output tables

| Subfolder | Contents |
|---|---|
| `icfes` | Cleaned ICFES records: numeric scores, valid status filter, outliers removed, English score imputed. |
| `internet` | Cleaned internet records: numeric access and speed columns, non-negative filter, outliers removed. |
| `bachillerato` | Cleaned educational coverage records: numeric indicators, coverage rate imputed. |
| `municipio_internet_cobertura` | Municipality-year aggregation of internet connections joined with educational coverage; includes derived column `accesos_por_habitante`. |
